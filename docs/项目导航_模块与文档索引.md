## 一、一句话 + 一条链

**做什么**：给定「RGB-D 视频流 + 一句自然语言」，输出目标物体在 3D 世界系中的**米制坐标**与空间关系。

**数据怎么流**（记住这条链就抓住了整个项目）：

```
RGBDFrame ──S1──> Detection2D ──几何层──> Observation ──S2──> SemanticObject
   ↑                                                            │
 data 层                                                    S3 推理
                                                                ↓
              ReasoningResult ←── SpatialRelation ←──────────────┘
```

| 契约 | 由谁产出 | 比上一格多了什么 |
|---|---|---|
| `RGBDFrame` | `data/` | 彩色 + 深度 + 内参 + 位姿 |
| `Detection2D` | `perception/`（S1） | 标签 + 分数 + 框 + 掩码 + 特征 |
| `Observation` | `geometry/` | **＋ 世界系 3D 点集**（关键一步） |
| `SemanticObject` | `mapping/`（S2） | 中心 + bbox + 融合特征 + 置信度 |
| `SpatialRelation` | `reasoning/`（S3） | 主体 + 关系 + 客体 + 米制距离 |
| `ReasoningResult` | 推理层收尾 | 可直接给机器人规划模块 |

## 三、四个"最能体现怎么实现"的地方

| # | 问题 | 答案（一句话） | 代码 |
|---|---|---|---|
| ① | 像素怎么变成米 | 针孔反投影 `x=(u-cx)·d/fx` → 再用 `Rᵀ(p−t)` 转到世界系 | `geometry/projection.py::backproject_detection` |
| ② | 多帧观测怎么串成"一个物体" | **实例关联**而非空间聚类：标签概念兼容 + 距离/IoU 达标 | `mapping/builder.py::_associate` |
| ③ | 开放词汇查询为什么两个阈值 | 词法（硬 0/1）与嵌入（软 0.7~0.9）尺度不可比 → 双阈值或逻辑 | `mapping/query.py::_accept_mask` |
| ④ | RL 怎么训 | RLVR：规则引擎当奖励（不需要 reward model）+ 组内优势 | `rl/reward.py`、`rl/grpo.py` |

### 补充：S3 空间关系 6 步判据链
`包含优先 → 三轴归一化分离量 → 取最大轴 → 强度不足则退化 → 竖直轴判 above/below → 水平轴"相邻优先"再判方向`
（`reasoning/spatial_relations.py`，详解见 `技术方案报告.md` 3.3）

### 补充：意图解析为什么不用分词
中文分词会把"桌子"切断。改用**词表召回**：词表 = 全部别名 + 地图标签（全量），按长度降序扫描原文，用区间占用避免重复匹配。
7 类意图优先级：`distance > list_on > count > nearest > relation > locate > describe`
（`reasoning/rule_engine.py`，详解见 `技术方案报告.md` 3.5）

## 五、实现哲学（三条主线，面试可讲）

1. **每个判据都要有"为什么不是另一个方案"的论证**
   —— 不用聚类用关联 / 不用单阈值用双阈值 / 不用平均用 max 兜底 / 不切词用词表召回。
2. **失败必须可归因，不能静默**
   —— `drop_stats` 记录丢弃原因；指标带样本量；奖励带分解（否则诊断不出 reward hacking）。
3. **降级路径是设计出来的**
   —— 感知注册表构造失败自动降级，整条管线永远能跑起来。
